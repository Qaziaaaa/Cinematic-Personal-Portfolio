# **App Name**: Andynocode AI Studio

## Core Features:

- Customizable Hero Section: Allow users to edit the community name, tagline, short introduction, and select multiple WebP background parallax image sequences via a CMS tool.
- Theme Customization: Enable users to select an accent color and toggle between dark and light modes, influencing the button backgrounds, highlight lines, section markers, and hover states via the CMS tool.
- Parallax Scroll Control: Implement a parallax scroll behavior where the scroll position maps directly to the WebP frame index, creating a smooth and responsive animated hero section.
- Content Management for Learning Paths: Provide a CMS tool for users to manage and update the text and content for each learning theme, ensuring fresh and engaging content for community members.
- AI-Powered Content Generation: Incorporate AI to suggest alternative taglines or descriptions based on the community name and focus areas. Use AI to suggest refinements to uploaded image assets, for better presentation.
- Student Showcase: AI curated list of the best student works.

## Style Guidelines:

- Dark color scheme: Charcoal background (#121212) for a cinematic feel.
- Primary color: Bright orange (#FF8C00) as the theme accent color, providing contrast and energy.
- Secondary color: Off-white (#F0F0F0) for text elements to ensure readability against the dark background.
- Body font: 'Inter', a grotesque-style sans-serif for a modern, machined look.
- Headline font: 'Space Grotesk', a proportional sans-serif with a computerized, techy feel.
- Minimal, monochrome social icons (YouTube, Instagram, X) centered at the bottom of the hero section.
- Single-page layout with a full-screen parallax hero section followed by distinct content sections: About, Learning Paths, Projects, Testimonials, FAQ, and CTA.
- Smooth fade-in/out transitions for text when switching themes or content. Subtle loading indicators during theme switches and initial frame loading.
